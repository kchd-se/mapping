# Healthcare Data Mapping Tool — v1

Schema-to-schema healthcare data mapping tool.  
**v1 scope:** schema import, catalog browse, field-mapping suggestions, validation, artifact export.

> ⚠️ **Non-negotiables**
> - No transformation script execution in v1.
> - No patient-level data ingestion.
> - Standards (FHIR, OMOP, …) are open/configurable — not hardcoded.
> - UI is contract-driven: all behaviour is derived from `apps/api/openapi.json`.

## First-time setup

```bash
# 1. Clone + enter
git clone <repo-url>
cd mapping_tool_v1

# 2. Python — create a virtual env and install
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS / Linux:
source .venv/bin/activate

pip install -r requirements.txt

# 3. Node — install root dev-tools (concurrently) + frontend deps
npm install
npm --prefix apps/web/ui install
```

## Running the application

### Full app (API + UI in parallel)

```bash

```

| Service | URL |
|---------|-----|

## openapi.json — how the UI consumes it

`apps/api/openapi.json` is the single contract between backend and frontend.

- FastAPI auto-generates it at `/openapi.json` at runtime.
- The checked-in file is regenerated by `npm run openapi` (runs `_gen_openapi.py`).
- The frontend's `apps/web/ui/src/api/` client is hand-maintained to match this spec.  
  Re-run `npm run openapi` after any backend schema change; then update the client accordingly.

**Do not** add or change API behaviour without regenerating this file.

## Manual verification checklist

After `npm run dev`, open http://localhost:5173 and walk through:

| Step | Action | Expected |
|------|---------|----------|
| 1 | Create a project | Appears in the list; status = `draft` |
| 2 | Import a source schema (JSON Schema payload) | Fields detected; source panel shows count |
| 3 | Browse catalog → pick a target schema + version | Target panel shows "Pinned" badge |
| 4 | Request mapping suggestions | Suggestion cards rendered per target field |
| 5 | Save a mapping version | Version label visible |
| 6 | Validate the mapping | Issues list (errors / warnings / info) |
| 7 | Export the mapping | JSON artifact downloaded; script field = Phase-6 placeholder |

Confirm no patient data is required at any step.
